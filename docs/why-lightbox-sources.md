# Why BT Projects Gallery — Reference Notes

The interaction design is adapted from the user-supplied Motion lightbox example at <https://motion.dev/examples/js-lightbox>. Its relevant pattern is a thumbnail gallery that opens a full-viewport overlay, preserving visual continuity between the selected thumbnail and expanded image. The implementation uses the project’s installed React Motion package to provide this continuity with layout-aware overlay transitions, rather than copying the example’s JavaScript source.

Gallery imagery was sourced through public image-provider search results and uploaded into the project’s managed static storage for deployment:

- `pump-maintenance-workshop_f4afac72.jpeg` — free stock water-pump workshop image returned as “Water Pump in a Workshop · Free Stock Photo.”
- `water-infrastructure-aerial_0c1429f5.jpg` — Unsplash water-infrastructure aerial image.
- `wastewater-treatment-aerial_10c73ccd.jpg` — Unsplash wastewater-treatment aerial image.

The gallery captions describe visual operating contexts only. They do not assert that the images depict BT Projects’ own completed work.
