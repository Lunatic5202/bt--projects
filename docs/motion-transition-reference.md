# Motion Transition Reference — Phase 30

The user supplied [Motion JavaScript examples](https://motion.dev/examples?platform=js) as the visual interaction reference on 20 August 2026.

The reference library explicitly presents production-ready snippets for React, JavaScript, and Vue. Its relevant categories are [Layout animations](https://motion.dev/examples?platform=js&category=layout-animations), [Interactions](https://motion.dev/examples?platform=js&category=interactions), and [Page transitions](https://motion.dev/examples?platform=js&category=page-transitions).

The BT Projects implementation will adapt the principles—not copy examples verbatim—through restrained staggered reveal timing, transform-and-opacity-only card feedback, visible keyboard focus states, and reduced-motion fallbacks. Rich curtain effects and animated text scrambling are intentionally excluded because they would compete with the site’s engineering content and water-infrastructure theme.
