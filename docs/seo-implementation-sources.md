# SEO Implementation References

- Google Search Central, **Organization structured data**: place Organization JSON-LD on the homepage and use relevant organization details such as name, URL, logo, contact details, and postal address. Source: https://developers.google.com/search/docs/appearance/structured-data/organization
- Google Search Central, **Robots meta tag specifications**: crawler directives belong in the document head and only work when crawlers can access the page. Source: https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag
- Google Search Central, **Canonical URL guidance**: use a self-referential canonical link in the document head, prefer absolute URLs, and keep sitemap URLs consistent with the canonical preference. Source: https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
